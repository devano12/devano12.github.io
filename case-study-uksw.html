Salatiga, Jawa Tengah | S1 Teknik Informatika

Fokus & Eksplorasi Akademik

Selama menempuh studi S1 Teknik Informatika di UKSW, saya memfokuskan diri pada pengembangan perangkat lunak secara komprehensif. Perjalanan akademik ini membekali saya dengan teori fundamental sekaligus praktik langsung dalam memecahkan masalah komputasi.

Mata Kuliah Utama & Implementasi

  • Pemrograman Berorientasi Platform: Mengembangkan arsitektur perangkat lunak dengan pendekatan berbasis platform, memahami siklus hidup aplikasi, dan penerapan version control menggunakan Git/GitHub.
  • Web Services: Merancang dan membangun RESTful API, mengelola integrasi basis data, serta mengimplementasikan sistem autentikasi modern (seperti JWT) untuk keamanan backend.
  • Grafika Komputer: Eksplorasi pemrograman visual 2D/3D menggunakan C++ dan OpenGL/GLUT, memanipulasi vektor matematika, dan mengolah rendering objek di layar.
  • Jaringan Komputer: Memahami infrastruktur, topologi jaringan, pengaturan router, manajemen bandwidth, serta konfigurasi server.
